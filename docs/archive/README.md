# Archive

Archived documents are historical references. They are not part of the normal active reading path.

Use archived files only when:

- investigating why an old decision was made;
- comparing a superseded roadmap with the current `docs/steps/` sequence;
- recovering context that is not present in active audits or `docs/PROJECT_STATUS.md`.

## Archive Policy

Files should be moved here instead of deleted when they still contain useful history but no longer guide current implementation.

Archived files may include:

- old broad roadmaps;
- market-specific roadmap sketches that are not the active implementation order;
- superseded reports whose conclusions were absorbed into newer baseline reports.

Do not treat archived phase numbers as current phase numbers. The active phase is always defined by `docs/PROJECT_STATUS.md` and the relevant `docs/steps/**` documents.

## Archived Roadmaps

- `roadmaps/ROADMAP_PHASES_07_20.md` - old broad roadmap through previous phase candidates.
- `roadmaps/market-roadmap/` - market-specific planning sequence that informed earlier career/market dependency work.

These files remain useful for historical context, but they are no longer implementation order.
