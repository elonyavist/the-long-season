## Decision Boundary

Step 12E prohibited a coefficient sweep, a second candidate and target movement
after output. Raising the `750 bp` volume coefficient would violate that
contract. Accepting effects below the frozen point floor would require an
explicit product amendment, not a calibration edit.

The recommended branch is to retain the point target and reject this
volume-only link. A future authorized design should make player-task execution
change the quality and type of the specific routes a plan demands, preserving
opportunity conservation and match variance. That is more football-readable
than multiplying generic volume, but it is a new product mechanism and is not
inferred as an implementation step here.
