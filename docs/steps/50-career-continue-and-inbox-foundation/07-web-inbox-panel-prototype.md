# 07 - Web Inbox Panel Prototype

## Goal

Add the first small Inbox / Posta panel to the career dashboard.

The panel should show manager-relevant messages created by the current
continue loop. It should not become a full mail client.

- `apps/web/src/screens/CareerDashboardScreen.tsx`

- `packages/i18n/src/catalogs/it.ts`

- `packages/i18n/src/catalogs/es.ts`
- `packages/i18n/src/catalogs/fr.ts`
- `docs/PROJECT_STATUS.md`
- The next relevant step document, only if a lesson learned changes future work.

## Implementation checklist

- Add a compact dashboard Inbox panel that renders the `CareerInboxView`.
- Show:
  - panel title;
  - unread count;
  - action-required count;
  - ordered message summaries;
  - priority/status indicators;
  - empty state.
- Make action-required messages visually clear without aggressive decoration.
- Keep layout dense, readable, and consistent with the existing premium-retro
  visual foundation.
- Add responsive behavior for narrow viewport.
- Add localized labels for all visible text.
- Add focused component tests.

## What NOT to implement

- Do not add a full Inbox route.
- Do not add compose/reply/archive/search/filter behavior.
- Do not add message persistence.
- Do not add market, contract, youth, finance, staff, or media message content
  unless generated by previous steps in this same phase.
- Do not make the panel decorative only; it must reflect structured messages.
- Do not use hardcoded visible labels.

- The career dashboard renders a small Inbox / Posta panel.
- Messages are driven by structured view data.
- The panel is localized and responsive.
- No full mail-client scope is introduced.
